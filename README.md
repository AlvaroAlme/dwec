# DWEC · Desarrollo Web en Entorno Cliente

Apuntes y ejercicios del módulo de Desarrollo Web en Entorno Cliente (ciclo DAW): JavaScript, Angular y React.

## Contenido

- `ut01` a `ut05`: ejercicios organizados por unidad temática.
- `examen-1ºeva`: ejercicios del examen de la primera evaluación.
- `practica-examen-final`: práctica del examen final.
- `APUNTES DWEC.docx` / `apuntes.txt`: apuntes de la asignatura.

## Tecnologías

- JavaScript
- Angular
- React
- HTML / CSS

## Nota

Este repositorio recoge apuntes y ejercicios realizados durante el módulo, no un proyecto único.
